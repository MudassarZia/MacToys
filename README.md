# MacToys

Mac utilities inspired by Microsoft PowerToys. An independent project, not affiliated with Microsoft.

**Download:** Open [Releases](https://github.com/MudassarZia/MacToys/releases), download `MacToys-0.1.0-universal.zip`, unzip it, and move **MacToys.app** to Applications.

Requires macOS 14 or newer. Works on Apple silicon and Intel. This alpha is not notarized, so macOS may block opening it.
